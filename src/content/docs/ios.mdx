# Sharing Files

To share files using InterShare on iOS:

1. Select the files you want to share.
2. Tap the **Share** button and choose **InterShare** from the list of options.

<img width="300" src="/docs/ios/select-intershare.png" alt="Select InterShare"></img>

InterShare will search for nearby devices, which may take a few seconds. Once the receiver's device appears, simply tap on it to start sharing.

<img width="300" src="/docs/ios/select-device.png" alt="Select Device"></img>

<br />

# Receiving Files

To receive files on iOS, ensure the InterShare app is running.

1. When someone shares a file with you, a popup notification will appear:

<img width="300" src="/docs/ios/request.png" alt="Incoming Request"></img>

2. Tap **Accept**, and the file transfer will begin.

<img width="300" src="/docs/ios/done.png" alt="Transfer Complete"></img>

Once the transfer is complete, InterShare will save the files in a designated folder on your iPhone. You can access the files by tapping the **Received Files** button within the app.
